# 🎮 Game Hub – Multi-Platform Gaming Platform

## Overview

Game Hub is a multi-platform gaming application developed using Python, offering both Web and Desktop gaming experiences. The platform features secure user authentication, score management, and interactive mini-games. The project demonstrates full-stack development concepts through Flask-based web services and desktop application development using Tkinter and Turtle Graphics.

Users can register, log in, play games, and track their scores through an intuitive interface. Game Hub is designed to showcase practical implementation of Python programming, GUI development, REST APIs, and data persistence.

## Installation

### Clone Repository

git clone https://github.com/your-username/Game-Hub.git

cd Game-Hub

### Install Dependencies

pip install -r requirements.txt

---

## Running the Web Version

Navigate to the Web-Version folder:

cd Web-Version

Run the Flask backend:

python backend.py

Open index.html in your browser.

---

## Running the Desktop Version

Navigate to the Desktop-Version folder:

cd Desktop-Version

Run the application:

python GAME.py
